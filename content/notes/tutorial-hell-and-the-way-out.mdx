Tutorial hell is what happens when watching feels like progress. You finish a
ten-hour course, you understood all of it, and you still cannot start a file
from scratch. The course did the thinking; you did the nodding.

The path on this site is sixty-five hours of video. Watched end to end, it is
an excellent way to spend a month and end up exactly there. So this section
exists for the other route.

## What the courses are actually teaching

Strip the frameworks away and the whole path teaches five things:

1. **The loop.** A model, a list of tools, and a `while` that keeps calling
   the model until it stops asking for tools. That is an agent. Course 03
   builds it in pure Python in under an hour.
2. **Control flow.** Once the loop has more than one branch you want to draw
   it, and once you draw it you want to run the drawing. That is LangGraph,
   course 04.
3. **Roles and handoffs.** Some problems split cleanly into a researcher, an
   analyst and a writer. CrewAI and the OpenAI Agents SDK are two ways to say
   that, courses 05 and 06.
4. **Context.** Retrieval, memory, and MCP, which is how an agent reaches
   tools that are not in its own process. Courses 07 and 08.
5. **Shipping.** Evaluations, guardrails, and something a client can pay for.
   Courses 09 and 10.

Everything else in the sixty-five hours is one of those five, said slower,
with a different library.

## The way out

The loop that works is short. **Read** a note here, in ten minutes, until you
can explain the idea to someone. **Build** it, from an empty file, without the
video open. **Watch** the course only when the build gets stuck, and skip to
the part that unsticks it.

<Callout label="Rule of thumb">
If you have not typed anything in twenty minutes, close the video. The course
will still be there. The thing you were about to understand will not.
</Callout>

That order matters. Watching first turns the build into copying. Building
first turns the video into an answer key, which is what it is good at being.

## What lives in this section

- **Notes** are one idea each, sized for a coffee. Most of the path will end
  up here, one concept at a time.
- **Articles** are longer, like this one: how to learn this, what to skip,
  what changed.
- **Docs** are reference. Patterns, checklists, the shape of an API, the
  things you come back to with a terminal open.

Start with [the agent loop](/notes/the-agent-loop-in-one-page). If you can
write that from memory, you are already past the point most tutorials leave
you at.
